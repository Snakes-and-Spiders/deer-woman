# Deer Woman

A top-down folklore horror quest played in the browser. You play Deer Woman, taking revenge on the Vescari crime family across a prologue, four chapters and free roam.

**Play:** https://snakes-and-spiders.github.io/deer-woman/

The tribe and story are fictional and inspired by folklore. The whole game is one HTML file with no dependencies, so you can also download `index.html` and open it locally.
